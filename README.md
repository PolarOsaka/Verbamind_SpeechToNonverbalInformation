# Verbamind: Speech-to-Nonverbal-Information

**Verbamind** is an audio processing tool designed to extract nonverbal speech cues—such as changes in loudness, pitch, speech rate, and pause detection. It is specifically tailored to assist in **psychological documentation and verbatim transcription analysis**.

## 📋 Features & Roadmap

- [x] **Loudness Change Detection** *(Active & Improved)*
- [ ] **Pitch Change Detection** *(In Development)*
- [ ] **Speech Rate Change Detection** *(In Development)*
- [ ] **Pause Detection** *(In Development)*

## 🚀 Current Functionality

Currently, the **Loudness Change Detector** is fully updated and operational. 

- **Input:** WAV audio file (`audio.wav`)
- **Output:** Frame-by-frame loudness classification:
  - `Very Low`
  - `Low`
  - `No Significant Change`
  - `High`
  - `Very High`
